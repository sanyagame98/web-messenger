Roof Premium Emoji Packs

Drop ZIP archives containing .tgs animated emoji files into this folder.
Do not unpack the ZIP files.

On startup Roof backend reads every ZIP in this directory and exposes the
collections only to the local Roof client. The client renders .tgs through
TWeb's built-in Lottie renderer.

You can add or remove ZIP files while Roof is stopped. After changing packs,
restart Roof or reopen the Premium Emoji picker to refresh the collection list.
